## Local features (no login)

Enable **Settings → Privacy → Local features** (restart may be required).

| Feature | Description |
|---------|-------------|
| **Local blacklist** | Hide content from blocked UP locally; no official block API |
| **Local follows** | Save UP pages; show “Following” on video / member pages |
| **Local playlists** | Multiple lists; multi-select / select-all; title sort; continuous play |
| **Local history** | Auto-recorded after playback |
| **Local watch later** | Add from video menu without login |
| **Import / export** | JSON import/export in settings |
